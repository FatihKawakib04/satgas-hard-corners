# Build Your First Crypto Dashboard with Crypto Data API

Crypto Data API is a free, keyless REST API providing market snapshots for 12 major cryptocurrencies.

**No API key. No signup. No payment.**

## Quick Start

```bash
curl https://satgas.ai.id/api/v1/coin/BTC
```

## What you get

- 12 major coins: BTC, ETH, BNB, SOL, XRP, ADA, DOGE, AVAX, LINK, DOT, TRX, LTC
- Prices, 24h/7d changes, market caps, volume
- Global market stats (total market cap, BTC dominance)
- Fear & Greed index
- Sentiment digest with freshness metadata
- Market snapshot refreshed every 15 minutes

## Starter Kit

Complete, runnable examples in 6 languages:
- Python (stdlib only)
- Node.js
- PHP
- Go
- Browser (vanilla JS)
- curl

All examples include timeout handling, 429 retry with backoff, freshness checking, and sentiment_stale handling.
